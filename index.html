Hinweise

DealFaz ist eine unabhängige Suchhilfe. Die Website ermöglicht das Öffnen externer Produktsuchen.

DealFaz stellt keine Verfügbarkeit, keinen Preis und keinen wirtschaftlichen Erfolg eines Kaufs oder Weiterverkaufs sicher.

Käufe und sonstige Verträge kommen ausschließlich zwischen dem Nutzer und dem jeweiligen externen Anbieter zustande.

Datenschutz

DealFaz verwendet eine technisch reduzierte Nutzungsanalyse mit PostHog.

Erfasst werden technische Ereignisse wie Seitenaufruf, ausgeführte Suche und das Öffnen eines Marktplatzes.

DealFaz übermittelt dabei über den eigenen Code keine Namen, E-Mail-Adressen oder eingegebenen Kontaktdaten an PostHog.

Session Recording und automatische Seitenelement-Aufzeichnung sind in dieser Integration deaktiviert. Die Analyse verwendet keine dauerhafte Browser-Persistenz durch DealFaz.

Bei Klick auf einen externen Anbieter verlässt der Nutzer DealFaz. Anschließend gelten die Datenschutzbestimmungen des jeweiligen Anbieters.
